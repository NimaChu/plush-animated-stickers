# 示例：羊羊 daily-v1

这是用本技能制作的完整一套示例，用来展示成品长什么样，不是制作规范，也不是必须复刻的模板。

羊羊是作者自有的白色长身绒毛角色，形象和这套成品都归作者所有，仅作为效果演示放在这里；本目录不包含原始参考图、身份记录、提示词和构建配置。
